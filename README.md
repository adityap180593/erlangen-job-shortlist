Only public vacancy information belongs here. Do not upload CVs, cover letters, contact details, candidate qualifications, personalised fit notes, application status, credentials, local file paths or private search history.

index.html is the latest completed report. Dated reports are saved under reports/YYYY-MM-DD.html. Preserve the category navigation, search filter, checked date and honest verification labels. Do not present old reports as freshly verified.

The existing daily search in Codex is scheduled for 09:00 Europe/Berlin and is responsible for searching and committing updates. GitHub Pages publishes main branch, root folder. GitHub does not search vacancies on its own. If the search or publishing fails, the visible checked date remains the previous successful report.

To edit from a Mac, sign in to the owning GitHub account, open index.html, select the pencil/Edit control, make the changes and commit. The public webpage can be read without signing in. Daily automated updates replace index.html; make permanent preference changes in the search instructions rather than only in this generated file.
